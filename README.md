🎤 GenAI Enabled Public Speaking Using Experiential Learning
Overcome stage fear using Virtual Reality and Generative AI
This project simulates a realistic VR audience and helps users improve their public speaking skills by generating intelligent feedback in real-time.

Developed using Streamlit, this web-based prototype integrates multiple AI technologies for an immersive, experiential learning environment.

🧠 Project Description
This project aims to help people overcome the fear of public speaking by simulating a realistic audience in Virtual Reality (VR).
The speaker's speech is transcribed in real-time, and intelligent questions are generated and delivered back to the speaker in audio format using AI.

🚀 Features
🎙️ Speech-to-Text
Transcribes user's speech in real-time using the speech_recognition library and Google Web Speech API.

❓ AI-Powered Question Generation
Generates insightful questions based on the speech transcript using Google Gemini API.

🔊 Text-to-Speech
Converts generated questions to realistic audio using the pyttsx3 library.

🎧 Audio Upload Support
Users can upload .mp3 files, which are converted to .wav for transcription.

🔄 Real-time Interaction
Users can interact with the app by speaking or uploading audio, and receive AI-generated questions and summaries in real-time.

📦 Tech Stack:
Frontend: Streamlit

Speech Recognition: speech_recognition, Google Web Speech API

AI Question Generation: Google Gemini API

Text-to-Speech: pyttsx3

Audio Processing: pydub, wave

Backend: Python
